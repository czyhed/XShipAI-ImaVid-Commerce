# 商品主图：模型直出 + 三套预制提示词模板

日期：2026-11-19。目标：给一张商品图，用提示词让图像模型直接画出带中文标题和卖点的电商主图。

## 为什么放弃「叠字」

先做过一版「无字底图 + 浏览器 Canvas 叠字」：模型只出底图，文字由代码排版。实测成品在排版层次、中文字形、商品质感和整体风格上都不达标，且对每张底图的留白要求很高。该方案已整体回滚删除，合成节点恢复原有的三图竖排 / 四宫格 / 单图满版拼图功能。

现在改为模型直出带字主图，文字效果取决于模型的中文字形能力；当前默认模型是 OMYAI 的 `gpt-image-2.5-flare`，中文长句仍需实测，必要时接 Qwen-Image 或 Seedream。

## 三套模板

| 模板 | 结构 | 适合 |
| --- | --- | --- |
| 主图 · 主视觉（左文右图） | 左侧品牌小字 + 两行主标题 + 圆角色块标签 + 白色胶囊规格条；商品在右 | 首图、主视觉 KV |
| 主图 · 卖点宫格 2×2 | 顶部通栏标题 + 商品居中 + 2×2 圆角卖点卡片 | 四个卖点集中表达 |
| 主图 · 规格参数图 | 右侧商品 + 左侧参数列表（标签 / 数值，组间分隔线） | 参数页、规格详情 |

三套都是竖版 3:4、`1024 × 1536`，播种时自动写成 `params.size = 1024x1536`。

## 提示词写法

- 文案用 `{{占位符}}` 标出，例如 `「{{主标题第一行}}」`；选择模板后直接在提示词框里把占位符替换成商品实际信息。
- 每段文字都放在引号里，并要求「完整、正确、简体中文、字形清晰」——模型对引号内的文字最听话。
- 明确禁止列表之外的内容：「不得出现列表之外任何文字、数字、字母、水印、价格或图标」。
- 要求保留包装：「100% 保留包装形状、印刷文字、logo、配色与比例」；这一条只有在**图生图**（带商品原图作参考）时才有意义。
- 字数约束：主标题每行 4–8 字；标签 4–6 字；规格条 ≤20 字；卖点标题 4 字、说明 ≤18 字；参数值 ≤12 字。字越少，出字越稳。

## 平台用法

1. 画布上加「生图」节点，把商品图连到图片输入端口（必须带参考图，纯文生图包装会走样）。
2. 右侧属性面板 →「高级参数与模板」→ 展开 →「提示词与参数模板」→ 选择三套之一。
3. 点「参数 JSON」确认 `size` 为 `1024x1536`；需要横版时手动改，但模板排版是按竖版写的。
4. 在提示词框里把 `{{…}}` 全部替换掉，数字只写商品资料里已确认的信息。
5. 预览运行，先出 1 张检查字形与排版，再批量。

## 播种机制

模板定义在 `web/src/lib/templates.js`，新增的三套带 `seedVersion: 2`。`server/creation-lifecycle.mjs` 的 `initSeed()` 按版本补发：

- 审计表 `sj_creation_audit` 里 `creation.template_seeded` 记录带 `detail.version`；旧记录没有该字段，按版本 1 处理。
- 已有工作区第一次打开「模板」列表时补齐版本 2 的三套；用户此前删掉的旧模板不会被重新写回。
- 模板 id 由 `workspace + template.id` 的 SHA-256 稳定生成，重复播种不会产生重复记录。

## 已知边界

- 中文直出没有百分之百的保证；同一提示词多跑几次字形也可能不同。先单张验证，再批量。
- 卖点宫格文字最多，失败率最高；可以先出主视觉/参数图，宫格后补。
- 模板只提供提示词与尺寸参数，不强制模型；换模型后效果可能明显变化，换模型需要重新验收。
- 模板是平台记录，可被编辑和删除；删除后不会自动恢复，需要重新选择或手动新建。
## AI 安排：三套「三张商品图」预设（2026-11-20）

AI 安排弹窗顶部新增「套图方案」tab（`POSTER_SETS`），选中后自动把预设描述填入创作要求，并把 `posterSet` 一起提交给 `/suggest`。服务端在规划提示词里追加该方案的固定槽位：必须产出三个 `generate` 节点，顺序与模板不可变，节点只填 `copy`（模板占位符的值），不写 `prompt` / `params`。应用安排时用 `renderTemplate` 渲染提示词，写入 `templateSnapshot`，参数固定为模板尺寸。

| Tab | 三张 | 模板 |
| --- | --- | --- |
| 转化三图 | 白底首图 · 卖点信息图 · 规格尺寸图 | `tpl-amz-white` · `tpl-amz-benefits` · `tpl-amz-specs` |
| 氛围三图 | 白底首图 · 场景图 · 细节特写 | `tpl-amz-white` · `tpl-amz-scene` · `tpl-amz-detail` |
| 图文三图 | 卖点信息图 · 场景图 · 规格尺寸图（三张全带字） | `tpl-amz-benefits` · `tpl-amz-scene` · `tpl-amz-specs` |
| 上新三图 | 白底首图 · 卖点信息图 · 场景图 | `tpl-amz-white` · `tpl-amz-benefits` · `tpl-amz-scene` |

约束与行为：

- 三张固定为 1:1、`1024 × 1024`；图文三图是唯一三张都带字的方案（当首图不需要白底时选它）；其余方案的白底首图模板没有任何占位符，提示词明确要求纯白底、无文字、商品占画面约 85%，对应亚马逊等平台「首图不带字」的规则。
- 文案语言跟随模板与实际填写；当前先出中文版，切英文只需替换占位符文案，模板结构不变。
- 商品资料里没有的信息（品牌、尺寸、参数）由模型省略，渲染后保留 `{{占位符}}`，应用后可在提示词框补；不会让模型编造。
- 应用后三个节点自动连上商品图（`ref` 端口）与提示词节点；确认弹窗按「模板名 + 已填文案」展示，而不是整段提示词。
- 模板随 `seedVersion: 3` 补发，已有工作区打开模板列表即可看到五套新模板。

代码位置：模板与方案在 `web/src/lib/templates.js`（`POSTER_SETS` / `seedVersion: 3`）；规划提示词与渲染在 `server/creation-projects.mjs`（`posterSetRules` / `renderPosterAddition`）；tab 与确认弹窗在 `web/src/components/CreationProjectCanvas.jsx`；单测 `tests/poster-amazon-sets.test.mjs`。
